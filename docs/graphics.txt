[== GRAPHICS ==]

== HARDWARE REGISTERS ==

FFC8      | 1 Byte   | Clear screen

FFC9      | 1 Byte   | (signed byte) x Position
FFCA      | 1 Byte   | (signed byte) y Position

FFCB      | 1 Byte   | Sprite width
FFCC      | 1 Byte   | Sprite height

FFCD      | 1 Byte   | Sprite address
FFCE      | 1 Byte   | Draw sprite

FFCF-FFFF | 48 Bytes | Color palette

== SPRITES ==
The MONKEDORE-64 only supports sprites

-- DRAWING SPRITES --
Set the x Position and y Position to where you want the sprite drawn.
This position is the position of the top left corner of the sprite.

Set the Sprite width and sprite height registers.
Set the Sprite address to where the sprite data is stored.

Set the value of Draw sprite
Set the lowest bit to the layer you're drawing on.
Set the second lowest bit to 1.
The sprite register automatically resets next cycle.

== CLEARING THE SCREEN ==
Set the value of Clear screen to 1
The register resets afterwards

== PALETTE ==
16 colors (4bpp)

The palette is stored in RAM and can be modified during execution

Color 0 is the backround color. On the foreground layer it is transparent, and on the backround layer it is colored in.
Color 0 is ignored when drawing sprites.
