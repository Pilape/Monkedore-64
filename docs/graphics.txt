[== GRAPHICS ==]

== HARDWARE REGISTERS ==

FFC8      | 1 Byte   | (signed byte) x position
FFC9      | 1 Byte   | (signed byte) y position

FFCA      | 1 Byte   | draw pixel

FFCB      | 1 Byte   | sprite width
FFCC      | 1 Byte   | sprite height
FFCD      | 1 Byte   | sprite address
FFCE      | 1 Byte   | draw sprite

FFCF-FFFF | 48 Bytes | Color palette


== SPRITES ==
The MONKEDORE-64 only supports sprites

== PALETTE ==
16 colors (4bpp)

Palette stored in RAM and can be modified during execution
