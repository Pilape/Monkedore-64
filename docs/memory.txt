[== MEMORY ==]

== STACKS ==
We have two stacks: the data stack and the return stack.
Both can store up to 256 16-bit words.

== RAM ==
We use 16-bit addressing which gives us 64KiB of RAM

-- MEMORY MAP --

Addresses | Size       | Use 
————————————————————————————————
0000-7FFF | 32 KiB     | ROM
8000-FEFF | 31.75 KiB  | General purpose RAM
FF00-FFFF | 256 Bytes  | I/O registers

-- I/O registers --

Address   | size     | Use
————————————————————————————————
FF00      | 1 Byte   | Button input

FF01-FFC7 |          | Unused

FFC8      | 1 Byte   | Clear screen

FFC9      | 1 Byte   | (signed byte) x Position
FFCA      | 1 Byte   | (signed byte) y Position

FFCB      | 1 Byte   | Sprite width
FFCC      | 1 Byte   | Sprite height

FFCD      | 1 Byte   | Sprite address
FFCE      | 1 Byte   | Draw sprite

FFCF-FFFF | 48 Bytes | Color palette
